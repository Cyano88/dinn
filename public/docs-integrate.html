Integrate Dinn research

Add research to a token page or request it from another agent. Start with the public API to verify the request and response before adding payments.

Run a public request

Send this from your server or shell. The public preview needs no wallet or API key. In the Dinn workspace, Integrate Dinn runs a Base or Robinhood example in your browser.

curl 'https://dinnlabs.com/api/agent/request' \
  -H 'Content-Type: application/json' \
  -d '{"service":"base.stock.research","requestId":"docs-quickstart","input":{"query":"NVDAc"}}'

Selected fields from a verified response:

{
  "service": "base.stock.research",
  "status": "completed",
  "charged": false,
  "result": {
    "chainId": 8453,
    "address": "0xb20000000000000000000078ee7ce2fe4908108c"
  }
}

Read result for structured evidence and deliverableMarkdown for the report. Display the network, checked time, source links and coverage notes beside the figures. Sanitize Markdown before displaying it as HTML.

Choose the service

Coinbase stock token on Base
base.stock.research with input.query, such as NVDAc or its contract address.
Bankr stock-paired launch on Base
base.stock-paired.research with the launch token in input.address. For discovery use base.stock-paired.discover with input.metric set to liquidity or volume. The shortlist covers a sample.
Robinhood stock token
pons.stock.research with the stock ticker or contract in input.query.
Pons launch on Robinhood Chain
token.research with input.address. For a launch paired with a stock token, use pons.stock-paired.research with the launch token's address.

Handle incomplete results

Check the HTTP status and the response's status. Omitting query in the example returns HTTP 200 with status: "needs_input" and missingFields: ["query"]. Supply the missing field before retrying. When the service returns HTTP 429, back off. A completed report can still have unavailable prices, partial holder coverage, or no verified lock record. Keep those states distinct from zero.
