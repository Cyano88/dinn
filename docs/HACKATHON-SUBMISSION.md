# NEAR Hackathon submission handoff

The [official rules](https://nearhackathon.com/HACKATHON.md) set the deadline at **14 November 2026, 23:59 UTC**. Check the live rules and form again before submitting. Submit only once, after the project lead has checked the exact payload.

## Evidence ready

- Public repository: https://github.com/Cyano88/dinn
- Baseline and new NEAR work: [README provenance](../README.md#hackathon-provenance) and [NEAR integration record](NEAR-MARKETPLACE.md).
- Live paid listing: https://market.near.ai/a/dinn
- Live Dinn app and free agent API: https://dinn-pasy.onrender.com and https://dinn-pasy.onrender.com/.well-known/dinn.json
- Reproducible request and reference agent: [README walkthrough](../README.md#reproduce-the-flow).
- Demo MP4: `output/dinn-prize-demo/Dinn-Labs-Product-Demo-V3.mp4` on the project computer. The filmed Grail report is a captured block snapshot, not a claim about today's token values. Buyer and seller in the paid hire were controlled by the same owner.

## Before the deadline

1. Review the refreshed demo MP4 with sound and captions. Confirm all on-screen proof is legible and the narrated facts match the recorded block.
2. Review the README, license, and the public diff from baseline. Publish the docs commit so the public repo contains the reproduction steps and license before submission.
3. The project lead publishes a public X post saying Dinn was built at NEAR HACKATHON, tagging `@NEARProtocol` and `#NEARHackathon`, with the demo video attached. Keep the public post URL.
4. Prepare the form's project name, lead name, email, team size, **Agent Economy** track, mainnet NEAR payout account, public repo URL, public X post URL, 20–2000 character build summary, and contact-consent choice. Verify the payout account with its owner; do not infer it from an EVM wallet.
5. Show the complete payload to the project lead and get explicit approval before the one-time submission. Keep the app, listing, and repository available through judging.

## Honest scope

The controlled $0.10 paid hire demonstrates funded assignment, report delivery, buyer acceptance, and marketplace payment release. It does not demonstrate independent customer demand, a separate autonomous agent hiring Dinn, or a withdrawal from marketplace balance to an external wallet. Those are useful future proofs, but they should not be invented in the submission. The reference agent demonstrates how a consumer verifies and uses the report without trading.
